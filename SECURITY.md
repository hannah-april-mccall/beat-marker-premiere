# Security

Audio analysis runs locally. The shipped engine and model do not require an online account or a runtime download. Analysis caches and saved operation data are stored separately from the installed extension.

Please report security problems privately using **Security → Advisories → Report a vulnerability** on this repository when that option is available. If private reporting is unavailable, open an issue asking for a private contact channel without including exploit instructions, credentials, private media or sensitive logs. A maintainer can arrange the next step there.

This is a community project with best-effort support and no guaranteed response time. Fixes target the latest prerelease; older builds may require an update.

Download packages from this repository's Releases page and compare the provided SHA-256 checksums when needed. Current builds have no paid OS publisher signing or Apple notarisation; read the [installation guide](docs/INSTALLATION.md) for unrecognised-publisher warnings and managed-computer limits. A specific malware alert is different from a missing-publisher warning.
